# AWS E-Commerce Data Lakehouse

## Project Overview

An end-to-end AWS data engineering project that builds a scalable e-commerce data lakehouse using AWS S3, Glue, PySpark, Athena,
Redshift, Lambda, IAM and Power BI.

## Business Problem

E-commerce businesses generate large volumes of customer, product, order and shipment data.

The objective of this project is to build a cloud-based data platform that ingests raw data, cleans and transforms it, performs data-quality
checks, and produces analytics-ready datasets.
